# **App Name**: MinuteMind

## Core Features:

- Secure Authentication: Enable users to securely log in and sign up using email/password authentication through Firebase or Supabase.
- Meeting Input: Allow users to upload meeting recordings/transcripts from various sources like Google Meet, Zoom, or upload .mp3/.wav/.txt files.
- Transcription Service: Automatically transcribe meeting audio using the Whisper API or AssemblyAI.
- AI-Powered MoM Generation: Generate structured Minutes of Meeting (MoM) using AI summarization, automatically filling in a predefined template or user-uploaded template.  Use a tool to decide which portions of the text will be placed into each part of the summary.
- Customizable Templates: Allow users to upload .docx files as editable templates, or choose from predefined layouts.
- Email Dispatch: Automatically dispatch the generated MoM to all meeting participants using Gmail API or SendGrid.
- Meeting History: Save a history of meetings and generated MoMs in the user's dashboard.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to evoke calmness and focus.
- Background color: Light gray (#F5F5F5), creating a clean, minimal interface.
- Accent color: Dusty rose (#D8BFD8) for buttons and highlights to maintain a gentle, unobtrusive interface.
- Headline font: 'Playfair', a serif for a fashionable, high-end feel; body font: 'PT Sans' (sans-serif) for a modern look in longer text.
- Use simple, clear icons for meeting controls and navigation.
- Maintain a clean and minimal interface with a white background and pastel accents, ensuring readability and ease of use on both mobile and desktop devices.
- Use subtle animations to provide feedback during transcription and generation processes.
